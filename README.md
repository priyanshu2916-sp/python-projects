# Python Projects

This repository contains two beginner-friendly Python projects.

## Project 1: ATM Simulator
- PIN verification with limited attempts
- Check account balance
- Deposit and withdraw money
- Transaction history

## Project 2: Student Marks Manager
- Add student marks
- View student averages and grades
- Find the topper
- Validate marks and student names

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run:

```bash
python python_project.py
```
